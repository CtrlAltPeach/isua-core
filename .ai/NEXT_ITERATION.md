## Кандидаты на итерацию 23

### Технический долг
- **Рефакторинг под модульный монолит** (низкий приоритет) — выделить чёткие доменные модули
  (абитуриенты, программы, пользователи, статистика и т.д.) с собственными границами API и
  минимизацией cross-module зависимостей. Подготовка к возможному расщеплению на микросервисы
  в будущем. Не срочно, выполнять по возможности в фоне. См. `.ai/MODULAR_MONOLITH.md`.
- Апгрейд Prisma 6 → 7 (требует `prisma.config.ts` + driver adapter) — не срочно.
- **Свернуть 8 groupBy в один SQL** (продолжение итер. 22): чистый Prisma `groupBy` не умеет
  условные count в одном вызове, поэтому сейчас 8 запросов. Если число запросов станет
  узким местом — один `$queryRaw` с `COUNT(*) FILTER (WHERE …)` + `AVG(totalScore)` отдаст
  все агрегаты одним заходом. Это будет первый случай сырого SQL в проекте. Не срочно:
  все 8 запросов параллельны и идут по `@@index([programId])`.

### Остаток бэклога

  - L1–L3, L5–L6, **nonce-CSP** (убрать 'unsafe-inline' в проде; требует dynamic rendering).
  - **B** (на пользователе): заменить боевые JWT_SECRET/ENCRYPTION_KEY в Vercel env.
