## Кандидаты на итерацию 19 (выбрать тему)

### A. Функциональные доработки
- **Сортировка по баллам** — при сортировке по убыванию сейчас в начале списка идут прочерки
  (null-значения); должны сначала показываться те, у кого балл рассчитан и видим. Небольшая,
  заметная пользователю правка (whitelist сортировки `SORTABLE` + SQL `NULLS LAST` в
  `applicants/route.ts`).
- **Сброс пароля пользователя админом** — в итерации 14 сделали только смену СВОЕГО пароля;
  сброс админом чужого пароля (через UserManager) отложен. Эндпоинт admin-only + инкремент
  tokenVersion целевого юзера.
- Экспорт CSV (без формул, для импорта в другие системы) — если понадобится в дополнение к XLSX.
- **Сортировка/перенос программ внутри группы** (drag-and-drop), если понадобится более тонкий
  порядок, чем `sortOrder` групп.

### B. Безопасность — остаток аудита (см. SECURITY.md)
- **M1: rate-limit in-memory → Redis** — нужно при нескольких инстансах / горизонтальном
  масштабировании (на одном инстансе текущий in-memory работает).
- **M4: ENCRYPTION_KEY в KMS/Vault** (сейчас env).
- L1–L3, L5–L6, **nonce-CSP** (убрать 'unsafe-inline' в проде; требует dynamic rendering).
- B (на пользователе): заменить боевые JWT_SECRET/ENCRYPTION_KEY в Vercel env.

## Заметки по инфраструктуре
- ⚠️ **Локальная БД сменилась (2026-06-22):** portable PostgreSQL 17 (`%LOCALAPPDATA%\isua-pg`)
  больше нет; на :5432 — системная служба **PostgreSQL 18** (`postgresql-x64-18`,
  auth `scram-sha-256`). `DATABASE_URL` в `.env` указывает на неё (пароль роли `postgres`
  задан при установке PG18). Каталог бэкапов portable-инстанса тоже исчез — настроить
  бэкапы для PG18 (см. `.ai/ops/DATABASE_ENVIRONMENTS.md`, раздел «Бэкапы / дампы БД»).
