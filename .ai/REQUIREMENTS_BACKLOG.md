## 8. Экспорт и отчёты — частично

- [x] PDF-отчёт (`/report`, клиентский print): паспортные данные, платные, маркеры О/П — итер. 5
- [x] **Экспорт абитуриентов в XLSX** (итер. 14). `GET /api/applicants/export` (exceljs):
  лист «Абитуриенты» (весь список, без фильтров) + лист «Статистика» со встроенными формулами
  (COUNTIF по статусам, AVERAGE/MIN/MAX баллов, % согласий/документов, разбивка по программам
  с конкурсом и AVERAGEIF). ПДн (паспорт/ИНН/СНИЛС/прописка) — колонки только для админа,
  расшифрованные. Кнопка «Экспорт» на странице абитуриентов.
- [x] **Группировка программ** в отчёте и XLSX (итер. 15): заголовки групп в таблице «Конкурс»
  отчёта; столбец «Группа» в листе «Статистика» экспорта.

## 8-bis. Учётные записи / аутентификация

- [x] **Смена своего пароля** (итер. 14, D2). `POST /api/auth/change-password`: проверка
  текущего, запрет совпадения с новым, инкремент `tokenVersion` (отзыв старых JWT) + перевыдача
  cookie. Модалка в шапке (десктоп + «Ещё»).
- [x] **Сброс пароля админом** (итер. 19). `POST /api/users/[id]/reset-password` (admin-only):
  хеш нового пароля + инкремент `tokenVersion` (отзыв всех сессий целевого юзера). Кнопка
  KeyRound + модалка в `UserManager`.
- [x] **Мульти-фильтры таблицы по маркерам** (итер. 19). Чипы-тогглы ОК/ОП/Согл./Док./Платн./
  Дистант; query-параметры бэка, комбинируются через AND.
- [x] **Сортировка NULLS LAST** (итер. 19). При сортировке по `totalScore` прочерки (null)
  уходят в конец списка.
- [x] **Email регистронезависимый** (итер. 14, D1). Нормализация `trim+lower` в Zod-схеме
  (register + login). Для существующих БД — SQL-нормализация в `ops/DATABASE_ENVIRONMENTS.md`.
