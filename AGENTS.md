# Рабочие правила ИСУА

Эти правила обязательны для всех сессий в этом проекте.

## Коммиты
- Коммит **только в конце итерации** или после **значимого объёма работы** (завершённая фича/подзадача, а не промежуточное состояние).
- Не коммитить ради «сохранить прогресс» — незавершённую работу оставляем в рабочем дереве.

## После завершения итерации (обязательно)
1. Обновить `.ai/CONTEXT.md` — текущее состояние, версию, стек, что сделано.
2. Обновить `.ai/REQUIREMENTS_BACKLOG.md` — отметить сделанное ✅, новые находки внести в реестр, обновить tracking-таблицу (§11).
3. Обновить `.ai/NEXT_ITERATION.md` — описать план следующей итерации, собрать в неё идеи из бэклога.
4. Обновить `.ai/CHANGELOG.md` — добавить запись о завершённой итерации.
5. Только после этого — финальный коммит итерации.

## Имена файлов
- **Все markdown-файлы всегда называются ЗАГЛАВНЫМИ буквами** (например, `CONTEXT.md`, `CHANGELOG.md`, `SECURITY.md`). Это правило и для существующих, и для новых md-файлов.

## Договорённости по проекту
- Зелёный акцент (emerald) + крупный шрифт в UI для позитивных метрик.
- Оранжевый для маркеров квот (О) и предупреждений.
- Серый для платных (П).
- При внесении изменений в данные абитуриента: логировать в `History`, пересчитать `totalScore`, снять блокировку.
- Временная зона по умолчанию определяется из браузера (`detectTimezone`); фолбэк — Europe/Moscow.
