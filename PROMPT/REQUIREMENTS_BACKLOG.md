## 1. БД: Новые поля в модель Applicant

## 3. Карточка абитуриента (Applicant Form Modal)

### 3.1 Структура вкладок (переупорядочивание)
**Новый порядок:**
1. **Основное** (ФИО, программа, статус)
2. **Документы и согласие** ← Переместить сюда (было ниже)
   - Чекбокс "Документы собраны"
   - Чекбокс "Согласие на зачисление"
   - Чекбокс "Особая квота" ← Новое
   - Чекбокс "Платно" ← Новое
   - Выпадающий список "Документ" (диплом/аттестат)
   - Паспортные данные (серия, номер)
   - Гражданство
3. **Баллы экзаменов**
   - Математика (база) — оценка 2-5
   - Математика (профиль) — баллы 0-100
   - Русский, Химия, Физика, Информатика, География — баллы 0-100
   - **Доп. баллы / ВИ** ← Новое, 0-100+ (может быть сверх 300)
   - Средний балл (авто-расчёт)
4. **Контакты** (телефон, email)
5. **Персональное** (прописка, ИНН, СНИЛС, заметки)
6. **История** (лог изменений)

### 3.2 Логика Математики (база vs профиль)
- [ ] **Взаимоисключающие поля:**
  - Если заполнен `mathBase` (оценка) → `mathProfile` должен быть disabled (серый, не редактируется)
  - Если заполнен `mathProfile` (баллы) → `mathBase` должен быть disabled
  - Если оба пусты → оба активны
- [ ] **При расчёте total_score:**
  - Если заполнен `mathBase` → использовать ТОЛЬКО mathProfile (если есть) ИЛИ mathBase исключить
  - Если заполнен `mathProfile` → исключить mathBase (как сейчас)
  - Логика: студент сдаёт ЛИБО базу, ЛИБО профиль (не оба)

### 3.3 Валидация полей
- [ ] Убрать возможность **изменения баллов экзаменов колесиком мыши** (wheel event)
  - Разрешить только клик и ввод с клавиатуры
  - Может быть через `onWheel={(e) => e.preventDefault()}`

### 3.4 Новые поля
- [ ] **"Документ"**: выпадающий список (диплом / аттестат)
- [ ] **"Паспорт"**: серия (4 символа) и номер (6 символов)
- [ ] **"Гражданство"**: текстовое поле или выпадающий список (Россия, Беларусь, и т.д.)
- [ ] **"Особая квота"**: чекбокс (default: false)
- [ ] **"Платно"**: чекбокс (default: false)
- [ ] **"Доп. баллы / ВИ"**: числовое поле (0-100+, может быть сверх ограничения)
