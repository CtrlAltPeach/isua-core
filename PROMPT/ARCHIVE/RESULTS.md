# ИСУА — Результаты работы

> **ИСУА** — Информационная система учёта абитуриентов
> Прототип интерфейса для приёмной комиссии вуза

---

## Описание проекта

Веб-приложение для учёта поступающих в вуз абитуриентов. Позволяет операторам приёмной комиссии вести базу данных абитуриентов, отслеживать статусы заявок, анализировать конкурсную ситуацию по образовательным программам и экспортировать данные.

Реализовано **4 интерактивных экрана**, полностью покрывающих ключевые сценарии работы приёмной комиссии.

### Почему этот стек

- **Next.js 16** — единый фреймворк для frontend + API, SSR/CSR на выбор
- **Prisma + SQLite** — нулевая настройка БД, один файл на диске, легко перенести на PostgreSQL для продакшена
- **shadcn/ui** — готовые доступные компоненты, кастомизируемые через Tailwind
- **Zustand** — простое глобальное состояние без бойлерплейта Redux
- **TanStack Table** — headless-таблица с сортировкой, фильтрацией, пагинацией из коробки
- **Recharts** — декларативные графики, интеграция с shadcn/ui ChartContainer

## Реализованные экраны

### 1. Дашборд (`/` — вкладка «Дашборд»)

Агрегированная статистика приёмной кампании.

| Элемент | Описание |
|---------|----------|
| **4 карточки метрик** | Всего абитуриентов, Новые заявки, Зачисленные, Средний балл |
| **BarChart** | Абитуриенты vs бюджетные места по программам |
| **PieChart** | Распределение по статусам (donut) |
| **Таблица конкурса** | Программа / Места / Абитуриенты / Конкурс (цветовая индикация) |
| **Круговой прогресс** | Процент собранных документов |
| **Прогресс-бары** | Доля каждого статуса |

Карточки «Новые» и «Зачисленные» кликабельны — ведут на список с фильтром.

### 2. Список абитуриентов (вкладка «Абитуриенты»)

Полнофункциональная таблица данных.

| Функция | Детали |
|---------|--------|
| **Поиск** | По ФИО / телефону / email, debounce 300мс |
| **Фильтры** | По статусу (4 значения) и по программе (8) |
| **Сортировка** | По ФИО, программе, статусу, баллам, дате |
| **Пагинация** | 25 / 50 / 100 на страницу, номера страниц |
| **Добавление** | Кнопка «Добавить» → модальный диалог |
| **Редактирование** | Клик по строке или «Редактировать» в меню |
| **Удаление** | Подтверждение + toast-уведомление |
| **Экспорт** | Кнопка «CSV» → скачивание файла |

8 колонок: ФИО, Программа, Статус, Баллы, Документы, Телефон, Дата, Действия.
Статусы — цветные Badge (emerald / amber / green / rose).

### 3. По программам (вкладка «Программы»)

Карточки образовательных программ с аналитикой.

Каждая карточка содержит:
- Название программы и бюджетных мест
- Прогресс-бар заполненности
- Конкурс (чел./место)
- Разбивка по статусам (Badge)
- Топ-3 абитуриентов по баллам
- Кнопка «Все абитуриенты» → переход на список с фильтром

### 4. По статусам (вкладка «Статусы»)

Kanban-доска с 4 колонками.

| Колонка | Цвет | Иконка |
|---------|------|--------|
| Новый | emerald | FileQuestion |
| На рассмотрении | amber | Clock |
| Зачислён | green | CheckCircle2 |
| Отклонён | rose | XCircle |

Внутри — прокручиваемые мини-карточки (ФИО, программа, баллы, документы). Клик → редактирование.

## API-маршруты

| Метод | Маршрут | Назначение |
|-------|---------|-----------|
| `GET` | `/api/applicants` | Список с фильтрами, поиском, пагинацией, сортировкой |
| `POST` | `/api/applicants` | Создание нового абитуриента |
| `GET` | `/api/applicants/[id]` | Получение одного абитуриента |
| `PUT` | `/api/applicants/[id]` | Обновление (с оптимистичной блокировкой) |
| `DELETE` | `/api/applicants/[id]` | Удаление |
| `GET` | `/api/programs` | Список программ с количеством абитуриентов |
| `POST` | `/api/programs` | Создание программы |
| `GET` | `/api/stats` | Статистика для дашборда |
| `GET` | `/api/export?format=csv` | Экспорт абитуриентов в CSV |

Оптимистичная блокировка: при `PUT` передаётся `version`. Если версия не совпадает → `409 Conflict`.
