# Frontend промпт: ИСУА (isua_core)

**Информационная система учёта абитуриентов**

---

## 1. Требования

### Функциональные
- Четыре вкладки: Dashboard, Абитуриенты, Программы, Статусы
- Авторизация (регистрация и вход)
- Полнофункциональная таблица абитуриентов с фильтрацией, сортировкой, пагинацией
- Редактирование с блокировкой записей (показать кто редактирует)
- Вкладка «По программам» с карточками и рейтингом
- Kanban доска по статусам
- Dashboard с метриками за день
- Генерация PDF отчёта за день (рейтинг + статистика)
- Экспорт в PDF
- История изменений с полным логом
- Выбор временной зоны в меню

### Вкладка: Dashboard
**Показывает статистику за сегодня, обновляется при открытии и при клике на кнопку «Обновить»**

Элементы:
1. **Карточки метрик (4 штуки, сверху)**
   - Всего абитуриентов в системе
   - Новых заявлений сегодня ⭐ (выделить красным или золотым)
   - Согласия на зачисление
   - Документы собраны (%)

2. **Таблица конкурса по программам**
   - Программа | Мест | Абитур. | Конкурс | Сред. балл | Согласия | Документы

3. **Таблица статусов**
   - На рассмотрении | Зачислено | Отклонено | Забрали | [Всего изменений сегодня]

4. **Кнопка "Скачать отчёт PDF"** (внизу)
   - Генерирует PDF с рейтингом и статистикой
   - Название: `отчет_ИСУА_YYYY-MM-DD.pdf`

5. **Кнопка "Обновить"** (для пересчёта статистики)

### Вкладка: Абитуриенты (главная таблица)

**Элементы управления (сверху):**
1. **Поиск** по ФИО, email, phone (debounce 300мс)
2. **Фильтры** (dropdown или multiselect):
   - По статусу (new, applied, withdrawn, accepted, rejected)
   - По программе (5 программ)
3. **Кнопка "Добавить"** (открывает модальное окно)
4. **Кнопка "Экспорт PDF"** (скачивает всех абитуриентов с баллами)
5. **Выбор временной зоны** (dropdown: Europe/Moscow, Asia/Yekaterinburg и т.д.)

**Таблица (8+ колонок):**
| ФИО | Программа | Статус | Баллы | Согласие | Документы | Телефон | Дата | Действия |

**Колонка «Статус» (цветные Badge):**
- new → серый
- applied → синий
- withdrawn → оранжевый
- accepted → зелёный
- rejected → красный

**Колонка «Согласие»:** ✓ (галочка, если true)

**Колонка «Документы»:** ✓ (галочка, если true)

**Колонка «Действия»:**
- Кнопка редактирования (иконка карандаша)

## 8. Детали редактирования

### При открытии записи на редактирование:
1. **Отправить `POST /api/locks/{id}`** → получить статус блокировки
2. **Если блокировка есть** → показать `"Сейчас редактирует: Иван Петров"`
3. **Если блокировка своя** → разрешить редактирование
4. **Начать отправлять heartbeat** каждые 10 сек
5. **При потере focus** или клике «Закрыть» → `DELETE /api/locks/{id}`

### При сохранении:
1. **Пересчитать total_score** на фронте
2. **Если статус → "withdrawn"** → consentToEnroll = false (в форме)
3. **Отправить PUT /api/applicants/{id}** с обновлёнными данными
4. **Если 409 Conflict** → показать сообщение "Данные были изменены другим пользователем"
5. **Снять блокировку** → `DELETE /api/locks/{id}`
6. **Обновить таблицу**
