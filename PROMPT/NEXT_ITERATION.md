## Кандидаты на итерацию 12 (выбрать тему)

### A. Инфраструктура БД — ICU/русская локаль
- Пересоздать кластер PostgreSQL с ICU-провайдером и локалью ru-RU (initdb).
- Убрать костыль `lower(... COLLATE "und-x-icu")` в raw SQL поиска, вернуть Prisma
  `mode: "insensitive"`. Затрагивает локальную БД, dev-preview и прод (миграция данных).
- Плюс: корректные ILIKE/сортировка по кириллице «из коробки». Минус: пересоздание кластера.

### B. Безопасность — остаток аудита (§13)
- M1: rate-limit in-memory → Redis (при горизонтальном масштабировании / нескольких инстансах).
- M3: ротация ключа шифрования (enc:v2 + dual-key read) — снимает боль «сменил ENCRYPTION_KEY
  → данные нечитаемы».
- M4: ENCRYPTION_KEY в KMS/Vault (сейчас env). L1–L3, L5–L6, nonce-CSP — мелкие.
- B (на пользователе): заменить боевые JWT_SECRET/ENCRYPTION_KEY в Vercel env.

### C. Полировка надёжности
- Retry/переподключение при потере соединения (5.3) — НЕ начато.
- Интеграционные тесты API-роутов (сейчас 36 unit-тестов на чистые функции).
- Заполнить README (запуск, env, миграции, деплой — частично есть в PROMPT/).
