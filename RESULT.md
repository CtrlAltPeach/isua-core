# ИСУА — Результат разработки (итерация 1)

> **ИСУА** — Информационная система учёта абитуриентов вуза.
> Приёмная комиссия ведёт базу абитуриентов, отслеживает статусы и согласия,
> анализирует конкурс по программам.

## Что реализовано

### База данных (5 моделей)
`Program`, `User`, `Applicant`, `History`, `Lock`. Миграции применены, есть seed.

- **4 программы:** ИСД, ТГСВ, ЗиК-КИ, ЗиК-ГК.
- **60 тестовых абитуриентов** (seed).
- Демо-пользователь: `admin@isua.local` / `admin12345`.

### Доменные правила
- **Статусы:** `applied` (Подал заявление, зелёный) и `withdrawn` (Забрал заявление, **красный**).
- **Согласие на зачисление:** можно при «Подал»; авто-снятие при «Забрал». История логируется.
- **Общий балл** = СУММА трёх наибольших предметных баллов (целые, макс 300).
  - mathBase (оценка 2-5) в расчёт НЕ входит.
  - Меньше 3 предметов → балл не считается (—).
- **mathBase:** красная иконка Σ рядом с ФИО, если заполнен.

### Backend (API)
| Метод | Маршрут | Назначение |
|-------|---------|-----------|
| POST | `/api/auth/register` | Регистрация (JWT + bcrypt) |
| POST | `/api/auth/login` | Вход |
| POST | `/api/auth/logout` | Выход |
| GET | `/api/auth/me` | Текущий пользователь |
| GET/POST | `/api/applicants` | Список (фильтры/поиск/сортировка/пагинация) + создание |
| GET/PUT/DELETE | `/api/applicants/[id]` | Чтение / обновление (history + 409) / удаление |
| GET | `/api/applicants/[id]/history` | Журнал изменений |
| GET | `/api/programs` | Программы с конкурсом |
| GET | `/api/stats/daily` | Статистика за день (по программам, согласия/места, новые) |

- **History:** логирование всех изменений (поле, старое→новое, кто, когда).
- **Оптимистичная блокировка:** `version` → 409 при конфликте.
- **Поиск:** регистронезависимый по кириллице (lower + ICU-collation).

### Frontend
- **Авторизация:** экраны входа/регистрации, защита маршрутов (редирект на `/login`).
- **Каркас:** шапка с 4 вкладками, выход, зелёный акцент (emerald), крупный шрифт.
- **Дашборд:**
  - 4 карточки метрик (всего / новые сегодня / согласия / документы %).
  - Таблица конкурса по программам (+ колонка «Новые сегодня»).
  - Блок «Новые заявления сегодня» — разбивка по программам.
  - Блок «Согласия / места» — прогресс-бары укомплектованности.
  - Сводка по статусам.
- **Таблица абитуриентов:** 11 колонок (ФИО, программа, статус, балл, согласие, документы,
  телефон, email, заметки, дата, действия), поиск (debounce, регистронезависимый),
  фильтры по статусу/программе, сортировка, пагинация (25/50/100), удаление с подтверждением.
  Оптимизирована под Full-HD (ФИО целиком, без горизонтального скролла).
- **Модальная форма add/edit:** все поля, math_base дропдауном, live-пересчёт суммы топ-3,
  согласие блокируется при «Забрал», валидация email, обработка 409.

## Запуск

```bash
# PostgreSQL (portable) — запуск кластера
& "$env:LOCALAPPDATA\isua-pg\pgsql\bin\pg_ctl.exe" -D "$env:LOCALAPPDATA\isua-pg\data" -l "$env:LOCALAPPDATA\isua-pg\server.log" -o "-p 5432" start

# Приложение
npm install
npm run db:migrate        # применить миграции
npm run db:seed           # засеять данные
npm run dev               # → http://localhost:3000 (или 3001)
```
